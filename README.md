# Transcribe Speaker Summary

Version: **2.1.0**

录音转写、时间戳、说话人标注和分人摘要。下载本目录不会自动安装依赖、模型或云服务，也不保证自动识别声音身份。

安装到你的技能目录后，用 `$transcribe-speaker-summary` 并提供音频。首次使用按 [SKILL.md](SKILL.md) 确认输出位置、格式与目录，再按 [环境配置](references/setup.md) 做检查。命令中的示例路径必须换成你自己的路径。

- [完整处理、说话人和恢复流程](references/transcription-workflow.md)
- [本地/云文档选择、md/txt/docx/doc、交付验收](references/output-format.md)

本包包含脚本与依赖清单，不包含模型、媒体、账号、令牌或作者的虚拟环境。云文档是可选路线，不依赖固定平台。`docx` 使用额外的可选依赖；旧式 `.doc` 需要另行确认转换工具。

2.1.0：从作者本机路径方案升级为可移植配置；新增交付选择、检查、断点恢复及导出，明确自动识别和人工核对的边界。默认输出行为改为尊重用户选择。

维护署名：Victor使用Codex制作。

安装时复制完整 `transcribe-speaker-summary/` 文件夹，不要只复制 SKILL.md；将它放到当前客户端实际识别的技能目录。作者这台Codex电脑的已安装目录是 `~/.codex/skills/transcribe-speaker-summary/`，`~`始终指当前用户自己的主目录；其他电脑/客户端按其实际配置，不创建作者用户名目录。

验证范围：核心离线行为测试，以及现有本地模型短样本、md/txt和基础docx内容导出。本轮未验证Windows/Linux、自动pyannote分离、云端连接和旧doc转换；Word导出未作视觉渲染验收。这些可选路线必须在目标环境分别验证，不能从核心测试结果推定已经通过。

2.1.0：新增可执行的本地自动声音分组脚本及词级时间对齐，输出中性说话人编号，保留重叠和不确定归属。新增可选独立分离环境依赖范围。自动分离真实模型尚未在作者机器配置/验证；当前新增验证仅覆盖离线接口与对齐行为。
